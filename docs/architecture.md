# 仕組み

## 全体

```
訪問者のブラウザ                        Cloudflare
┌─────────────────────┐    GET /widget.js   ┌──────────────────────────┐
│ サイトのページ        │ ─────────────────▶ │ Worker（src/worker.js）   │
│  └ 画面（Shadow DOM） │    POST /chat       │  ├ chat.js    ── Workers AI │
│                      │ ─────────────────▶ │  ├ contact.js ── Turnstile  │
│                      │    POST /contact    │  │             └ Resend（メール）│
│                      │ ─────────────────▶ │  └ report.js（毎月1日）     │
└─────────────────────┘                     │ KV：1日の回数  D1：会話の記録 │
                                             └──────────────────────────┘
```

- サイトには `<script src="https://<Worker>/widget.js" defer></script>` を1行置くだけ
- 画面は、配られた URL のオリジンを通信先にする（URL を二か所に書かない）
- 画面の設定は、Worker が `/widget.js` の先頭に付けて配る（`window.__chatFairyConfig`）。秘密の値・指示文・宛先は画面に渡さない（`widgetConfig()`）

## POST /chat

1. 入力の確認（空・長すぎ）
2. 同じ IP の1日の回数（`limits.perIpPerDay`）。超えたら AI を呼ばず、受付だけ出す
3. サイト全体の1日の回数（`limits.sitePerDay`）。超えたら AI を呼ばず、持ち主にその日1回だけ知らせる
4. AI を呼ぶ（指示文＋直近の会話＋質問）
5. 答えの後始末（`reply.js`）
   - 受付の印を外す。問い合わせのボタンを出すかは、AI の印ではなく、質問の言葉と答えで決める
   - 指示文が漏れたら、決まった文に差し替える
   - 相談の申し出に「お答えできません」と返したら、受付の案内に差し替える
6. 返事のあとで、会話を D1 に記録する（名前・連絡先は入れない）

回数は UTC の日付で区切ります。Workers AI の無料枠と同じく、日本時間の9時に戻ります。

## POST /contact

1. 入力の確認（名前・メールアドレス・内容）
2. 同じ IP の1日の件数（`limits.contactsPerIpPerDay`）
3. Turnstile の確かめ
4. 件名（どのサービスの話か）を、会話の言葉から付ける。決まらなければ、受付を始めたボタンの件名
5. 持ち主への知らせを送る。送れなければ受け付けていないので、失敗を返す
6. 件名と日時だけ D1 に記録する
7. 送った人への控えを送る。控えだけ失敗しても、受付は済んでいるので成功を返す（`replySent: false`）

## 月ごとの集計（毎月1日 0:00 UTC）

先月（日本時間の暦）の5項目を、持ち主にメールで送ります。

1. 数字（会話した人・受け答え・受付・答えられなかった回数・上限に達した日。先月比）
2. よく聞かれたこと（サービス別・ボタン別）
3. 答えられなかった質問の全文
4. ページと違う金額を答えた疑い（答えの「○○円」を `allowedYen` と照らす）
5. 受け付けた問い合わせ（日付と件名だけ）

あわせて、保存期間（`retentionDays`）を過ぎた記録を消します。

## 記録（D1）

表の形は `migrations/`。

| 表 | 入れるもの | 入れないもの |
|---|---|---|
| messages | 日時・会話の札（タブごとの乱数）・ページ・押したボタン・質問・答え・件名・答えられなかったか・受付を勧めたか・上限で止めたか | IP アドレス・受付で入力された名前などの中身 |
| contacts | 日時・会話の札・件名 | 名前・メールアドレス・相談の中身（持ち主へのメールにだけ載る） |

## 画面

`src/widget/` を esbuild で `dist/widget.js` に1つにまとめます（`npm run build`。wrangler の `build.command` からも呼ばれる）。

| ファイル | 中身 |
|---|---|
| index.js | 組み立て・会話・受付の画面 |
| contact-flow.js | 受付の手順（名前 → メール → 内容 → 確認）。画面に依存しない |
| session.js | タブの中の会話の記録（sessionStorage） |
| motion.js | 案内役の動き。位置の計算は画面に依存しない |
| styles.js | 見た目。色は設定から CSS の変数に入れる |
| text.js | HTML の無害化・URL のリンク化 |

## 守りの決まり

- 呼び出し元（Origin）は `allowedOrigins` だけ。手元の試験（`TEST_MODE=1`）のときだけ `localhost:8788` も受け付ける
- Origin は偽装できるので、回数の制限は IP で数える
- 指示文は外に漏れる前提で書く。秘密を入れない
- 秘密の値（`TURNSTILE_SECRET`・`RESEND_API_KEY`）は Cloudflare の秘密の設定にだけ入れる
